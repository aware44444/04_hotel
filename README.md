## 概要

yomoyomo stay は、静かな町家ステイをテーマにした学習用の宿泊施設サイトです。

HTML / CSS / JavaScript の基礎学習と、Git / GitHub を使った制作管理の練習を目的として制作しました。  
トップページ、お部屋紹介ページ、お問い合わせページを持つ、小規模な複数ページ構成の静的サイトです。

## 工夫した点

### CSS変数による色管理

サイト全体の配色を変更しやすくするため、主要な色をCSS変数として管理しました。  
これにより、メインカラーや背景色を一か所で変更できるようにしています。

### レスポンシブ対応

PC表示だけでなく、スマホ表示でも読みやすくなるように、余白、文字サイズ、カードの並びを調整しました。  
また、スマホではハンバーガーメニューを表示し、ナビゲーションを使いやすくしました。

### JavaScriptによるUI実装

FAQアコーディオン、宿泊プランのタブ切り替え、フォームの簡易バリデーションなど、静的サイトでよく使われる基本的なJavaScript機能を実装しました。

### Gitによる履歴管理

作業単位ごとにコミットを行い、変更内容を後から確認できるようにしました。  
READMEの修正とCSSの修正を別コミットに分けるなど、変更単位を意識して管理しました。
